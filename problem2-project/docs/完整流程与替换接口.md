# 问题 2 完整运行流程与替换接口

本流程覆盖数据读取、标准化、局部缺失增强、训练、验证选模、缺失规律分析、错误定位、附件 3 无标签推理和复现材料打包。当前默认采用 aligned，文本分支为随机初始化词元嵌入，不把它视作最终预训练编码方案。

## 一条命令完成小规模实验

当前项目的 `.venv` 已安装依赖。若在另一台机器或解压后的新目录复现，先准备 Python 3.10，在 problem2 中执行 `python -m venv .venv`，然后安装：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install torch==2.14.0+cpu --index-url https://download.pytorch.org/whl/cpu
```

复现包不含赛题原始数据。将 E题 数据目录放在 problem2 的同级目录，或修改配置中的 feature_path 和 special_folder。具体已测试版本保存在 report.json 的 environment 中；严格复现时按该版本安装。

在 problem2 目录运行：

```powershell
.\.venv\Scripts\python.exe workflow.py run --config configs/small.json
```

默认输出到 outputs/end_to_end_small。为避免覆盖已经训练的模型，非空输出目录会报错。重复实验使用新的目录：

```powershell
.\.venv\Scripts\python.exe workflow.py run --config configs/small.json --output outputs/end_to_end_repeat
```

默认配置从官方训练集与验证集按固定种子分别随机选取 512、128 条样本，保留官方划分，抽样不使用标签。标准化也只拟合这 512 条训练样本。最多训练 8 轮，连续 3 轮验证评分未改善则提前停止。

配置三组实验：

- clean_concat：无人工缺失增强，拼接融合。
- augmented_concat：有缺失增强，拼接融合。
- augmented_gated：有缺失增强，门控融合。

三者共用数据、标准化和验证区间；普通与增强拼接模型以相同随机种子初始化，门控模型因结构不同而有不同参数量。一次小规模运行不是多种子显著性检验。

## 运行阶段

1. 读取附件 2 的 train/valid，检查接口和样本 ID，按配置取子集。官方 test 不用于模型评价或调参。
2. 在当前训练子集可用位置拟合标准化，保存 standardizer.json。
3. 建立固定验证场景库。默认含完整输入及 7 个模态组合 × 3 个比例 × 4 个位置，共 85 情景。增加验证种子会扩展场景数。
4. 逐实验训练。增强以每个样本 50% 概率执行，随机选择模态组合、位置及 10%/30%/50% 比例。每轮变化可由 seed、epoch、sample_id 复现。
5. 每轮在完整输入及三模态随机 30% 缺失这两个固定验证情景上计算选择评分。默认评分是 MAE + (1−Macro-F1) 的情景均值，越低越好；该权重是明确的暂定工程选择。
6. 保存每组 best.pt 与 last.pt，前者是最佳轮次推理参数，后者包含最后一轮优化器和随机状态。用最佳参数在全部验证情景上评价。
7. 根据同一个预先设定的选择评分选出模型，导出 selected_model.pt、图表、错误案例和结果报告。
8. 对附件 3 对齐版 30 条样本推理。文件使用 DRAFT 命名，表示列名和样本追踪键尚待对应正式提交规范。

## 模型与损失

文本词元先通过可替换的文本编码器，音视频先投影到共同隐藏维度；默认音视频编码器再使用一维卷积提取局部序列上下文。投影前对不可用输入做掩码，编码后也屏蔽不可用位置，然后做掩码均值聚合。

拼接融合直接连接三模态表示。门控融合将每个模态表示与其可用位置比例一起输入评分网络，对有可用信息的模态归一化权重并求加权表示。全模态无可用信息时，融合表示为零，输出由头部偏置等确定，仍保证有限值；这不表示能够可靠恢复没有信息的情感。

分类头输出三类 logits，强度头使用 3×tanh 将输出限制在 [-3,3]。默认损失为分类交叉熵加 SmoothL1 回归损失。MSE、MAE 以及两项权重均可配置。分类和回归暂时独立输出，不强制符号一致；报告记录不一致案例。

## 可替换模块

组件支持注册名称，或者 `模块路径:工厂名称`。动态入口应指向你自己维护的可信代码。配置文件不应来自不可信来源。

| 模块 | 当前入口 | 替换时必须保持的接口 |
|---|---|---|
| 数据读取与原始掩码 | data.adapter → workflow_data:AlignedAdapter | load(seed) 返回 train/valid，special() 返回无标签数据；样本遵循 Dataset 字典协议 |
| 标准化 | preprocessor → masked_standard | fit(dataset, split)、transform(sample)、save(path)、类方法 load(path) |
| 文本编码器 | model.text → embedding / local_bert | forward(batch, text_pool_mask) 返回 [B,T,H] |
| 音视频时序编码器 | model.sequence → linear / temporal_conv | forward(features, observed_mask) 返回 [B,T,H] |
| 模态融合 | model.fusion → concat / gated | forward([B,3,H], [B,3]可用比例) 返回 [B,D]；提供 output_dim |
| 训练增强 | augmentation → workflow_data:MixedMissingDataset | 可索引 Dataset，支持 epoch 属性，返回同样的样本字段 |
| 损失 | loss → joint | callable(logits, intensity_prediction, class_label, intensity_label) 返回标量 |
| 验证选择评分 | selection → workflow_data:SelectionScore | callable(list_of_metric_dicts) 返回越低越好的标量 |
| 预测文件格式 | export → workflow_data:DraftExporter | export(path, predictions)，检查结果并写文件 |

数据源路径、样本量、特殊词元排除、训练轮次、学习率、损失权重、增强比例与概率、验证情景和实验列表均在 configs/small.json 中。

注意：experiments 中的 fusion 字段会覆盖 model.fusion，方便做对照；使用自定义融合工厂时将 experiment.fusion 填为对应的 `模块:工厂`，工厂接受 hidden 参数。如果需要额外参数，应扩展实验配置合并逻辑。

## 切换预训练文本编码器

实现了 local_bert 离线适配器，但当前实验未调用，也未下载外部模型。该可选路径需要另行安装 transformers，并提供本地权重：

```json
"text": {
  "name": "local_bert",
  "model_path": "本地已核验的模型目录",
  "tokenizer_verified": true,
  "freeze": true
}
```

只有确认赛题 token IDs 与该 tokenizer 的词表、特殊词元、大小写处理相容后才能设置 tokenizer_verified=true。训练、验证与附件 3 使用同一编码器。更改编码器后重新训练，不能沿用随机词元嵌入模型的分类头就声称完成迁移。该路径的真实预训练模型集成仍待执行；已测试未确认 tokenizer 时会明确拒绝运行。

## 改变掩码与特征版本

原始可用位置、特殊词元和 extent_mask 的生成由数据适配器负责，连续缺失计划由 pipeline.py/scenarios.py 负责。确定新规则后，重新生成场景库并重新拟合训练标准化器；旧场景的掩码指纹不匹配时会拒绝应用。

当前验证场景生成器使用共同 aligned 序列坐标。unaligned 的长度语义尚未解决，因此不能只换一个文件路径就运行；需要提供相应的数据适配器、独立时序缺失规则并扩展场景生成。这一限制是明确保留的接口边界。

## 独立预测与恢复

训练完成后重新加载模型，单独执行无标签推理：

```powershell
.\.venv\Scripts\python.exe workflow.py predict --config configs/small.json
```

此命令读取运行目录中保存的 config.json、selected_model.pt 和 standardizer.json，校验标准化哈希，不拟合任何统计量，不读取专项标签。

last.pt 支持使用 torch_training.restore_checkpoint 恢复到 epoch 边界，搭配相同 Dataset、增强种子、批大小与损失配置调用 train_epoch。当前 workflow run 为新实验入口，不提供自动续跑 CLI；底层 CPU 恢复一致性已经测试。GPU 与 batch 中途恢复未验证。

## 结果文件和打包

RESULTS.md 是面向阅读的结果报告；metrics.csv 和 validation_predictions.csv 包含完整评价记录。diagnostics.png 包含训练选模曲线、混淆矩阵和回归散点图，missingness_curves.png 对比随机连续缺失下的性能。error_cases.csv 和 error_by_class.csv 用于定位失败样本，不能当作因果解释。

```powershell
.\.venv\Scripts\python.exe workflow.py package --config configs/small.json
```

打包代码、配置、选中模型、标准化参数、结果摘要与草稿专项预测，不包含虚拟环境、原始数据和所有优化器 checkpoint，并检查不超过 50 MB。包名 preliminary_reproduction.zip 表明它是初步复现包；正式提交前仍需确定 CSV 格式、样本编号、编码器和论文结论。
