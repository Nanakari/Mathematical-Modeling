# 问题 2 数据检查与待确认事项

本报告来自本地赛题数据的实际只读检查。完整字段与计数见 `outputs` 中的 JSON，检查不改变数据和官方划分。

## 数据规模与标签

两套特征均为训练 3395、验证 728、测试 727 条，共 4850 条。没有发现划分内部重复样本 ID、跨划分重复样本 ID 或跨划分 video_id 重叠。检查的特征数值未发现 NaN/Inf。各字段样本数一致。

| 划分 | 负向 0 | 中性 1 | 正向 2 |
|---|---:|---:|---:|
| train | 967 | 758 | 1670 |
| valid | 206 | 184 | 338 |
| test | 207 | 158 | 362 |

全部分类标签均符合 `classification_labels = sign(regression_labels) + 1`。这只是标签编码核查，不意味着预测端已确定使用回归阈值生成分类。

## 零值与填充不等价

对齐版训练集：

- 文本特征没有全零行，但 BERT attention 候选有效范围以外仍有 86078 行非零文本特征。必须显式屏蔽填充，不能靠文本零值推断长度。
- 语音在候选有效范围内有 6855 行全零值，视觉有 11039 行。
- 按当前候选范围，110 条训练样本、15 条验证样本和 28 条测试样本没有可用的非零视觉行。这些样本保留。
- attention 为二值前缀掩码。训练和验证有效位置数范围是 3–50，测试是 4–50。

这些现象可能涉及特殊词元位置、原始提取无效行或其他数据生成规则。目前不能直接将其全部解释为模态损坏。

非对齐版的视觉特征在 `vision_lengths` 声明范围外仍有非零行：训练 36928、验证 8455、测试 10222 行。文本填充现象与对齐版相同。音频声明范围外未发现非零行。长度语义应进一步核对；暂不修改原始长度字段，也不自行将最后非零位置当作正确长度。

## 附件 3 全量接口检查

| 按形状推断的版本 | 文件数 | 实际字段 | 当前连续特征管线缺少 |
|---|---:|---|---|
| 对齐 | 30 | text_bert、audio、vision | text；另无 id |
| 非对齐 | 30 | raw_text、audio、vision | text、text_bert、audio_lengths、vision_lengths；另无 id |

每个文件顶层为 `test`，各文件包含一条样本。对齐版 audio/vision 序列长度为 50；非对齐版为 500。文件名保存在审计报告，可用作临时追踪键，但不是已确认的提交样本编号。

这里的“不兼容”仅指本次直接使用连续 text 特征的候选管线，不能据此认定专项数据无法建模。赛题允许选择 text_bert 路径；如改用该路径，需要明确编码器与输入处理，并在训练、验证和专项推理中使用同一流程。非对齐版本还需要澄清长度及文本缺失如何表示。

## 留待正式方案确定的事项

| 事项 | 已有处理 | 正式实验前需明确 |
|---|---|---|
| 特征版本 | 两版已检查，预实验使用对齐版 | 最终训练/验证/专项一致版本 |
| 特殊词元 | 保留 attention 指示位置 | 特殊词元与音视频位置关系 |
| 原始零行 | 记录并暂作不可用 | 数据缺失、填充和无效提取的区分 |
| 非对齐视觉长度 | 保留提供字段 | 字段语义及范围外非零值的原因 |
| 缺失率 | 按有效序列位置计，并记录新增丢失数 | 最终统计分母、区间长度和多模态组合 |
| F1 | 同时输出宏平均、加权和各类 F1 | 主报告采用的口径 |
| 分类/回归一致性 | 分别输出 | 是否约束一致，阈值只能在验证集确定 |
| 专项文本输入 | 完整记录接口差异 | 同一文本表示的可执行路径 |
| 提交 CSV | 已有内部预测日志 | 官方字段名称、样本编号和顺序 |

以上事项不阻碍已完成的数据体检、模拟器、测试和论文框架，也不需要引用问题 1 或问题 3 的结果。
