# 局部模态信息缺失条件下的情感预测方法草稿

以下内容是问题 2 的方法框架。符号和暂定实现可在共同规则确定后替换，实验结论尚未填写。

## 任务定义

第 i 条样本包含文本、语音、视觉三个模态的特征序列 X_i^m，其中 m∈{t,a,v}。输出为情感极性 y_i^c∈{0,1,2} 和连续情感强度 y_i^r∈[-3,3]。三类数字编码依次对应负向、中性和正向。训练和验证使用赛题附件 2 的既定划分。

## 有效位置和局部缺失

定义 V_i^m 为有效位置掩码，A_i^m 为人工遮蔽前的可用位置掩码，D_i^m 为模拟缺失掩码。模型使用的观测掩码为 O_i^m=A_i^m·(1-D_i^m)。V 与 A 分开记录，避免将序列填充与有效范围内的信息不可用混为一谈。

连续缺失用序列坐标上的半开区间 [s,s+ℓ) 表示，区间之外 D=0，区间之内 D=1。名义缺失比例 ρ 对应预算 floor(ρ·sum(V))，再受局部缺失约束限制。实际比例由实际被遮蔽的有效位置数除以有效位置数计算；同时记录其中原先可用的位置数。

赛题特征没有提供逐词时间戳，因此本文这一层的区间长度单位为序列位置，不能未经标定换算为秒。非对齐模态的序列坐标不代表共同物理时间，同步区间仅在确认的共同对齐坐标上定义。

## 已实现的轻量模型

各模态首先投影到共同维度：H_i^m=tanh(X_i^m W_m)。然后对可用位置进行掩码均值聚合：

z_i^m = sum_t(O_it^m H_it^m) / max(1, sum_t O_it^m)。

将三个模态表示拼接为 z_i。分类头给出 p_i=softmax(z_i W_c+b_c)，回归头给出 r_hat_i=3 tanh(z_i W_r+b_r)。若某模态没有可用位置，其聚合表示为零；样本仍保留。

候选训练目标为 L=λ_c L_CE+λ_r L_MSE。两个权重属于待选超参数。当前 NumPy 实现已完成正向、解析梯度及数值梯度验证，尚未在全量数据上训练。此结构没有时序上下文编码或跨模态重建能力，是可替换的工程基础。

## 已运行的基线

为快速验证整条数据链路，另采用原始特征的掩码均值池化，将三个模态拼接后分别训练逻辑回归分类器和岭回归强度预测器。标准化统计量仅由训练输入拟合，回归结果截断到 [-3,3]。该基线与上述可训练投影模型应在论文中明确区分。

普通基线使用原始训练输入；增强基线额外使用一份人工连续遮蔽输入，标签保持不变。两者在相同验证样本和相同遮蔽区间上比较。正式消融应固定标准化等其他处理因素。

## 验证设计

分别控制缺失模态组合、连续区间位置、区间长度和缺失段数，考察分类与回归性能。分类记录 Accuracy 和多种 F1 口径；回归记录 MAE 与 Pearson。以原始输入为参照，记录每种缺失情景的性能变化。最终的模型选择和阈值选择仅使用验证集。
